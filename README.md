# Node.js Feature-Based Boilerplate

A production-ready Node.js API template using **Feature-Based Structure (Vertical Slices)**.

## 🚀 Getting Started
1. Install dependencies: `npm install`
2. Create a `.env` file based on `.env.example`.
3. Start the server: `npm start`

## 📁 Architecture
- `src/features/`: Contains the business logic divided by features (Vertical Slices).
- `src/middlewares/`: Contains global middlewares (Error Handling, Auth).
